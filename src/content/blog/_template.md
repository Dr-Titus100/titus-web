Copy this file, rename it (for example `my-first-post.md`, without the underscore) and write the post in Markdown.
The file name becomes the address: /blog/my-first-post/. Set `draft: false` to publish it.
Set `fiction: true` for a story. The post then shows a "Fiction" label on the blog list, the home page and the post itself.
List the post's topics in `tags`. Readers can filter the blog list by them. Reuse a tag that exists when it fits, such as "AI writing", "Research" or "Release".
